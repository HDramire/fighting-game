## Practical protection notes

- Copyright protects the code, art, text, and other original content in this repository.
- Copyright does not protect a high-level game idea, genre, or general mechanic by itself.
- A public frontend cannot keep its client-side JavaScript, HTML, CSS, and shipped assets secret from
  users who load the site.
- If any mechanic, balancing data, roadmap, or monetization logic must stay secret, keep it out of the
  public client and out of a public repository.

## Repo hygiene

- Keep the repository private unless you intentionally want others to see the source.
- Keep secrets in local `.env` files only.
- Enable the bundled pre-commit hook:

```powershell
git config core.hooksPath .githooks
```

- Review `.gitignore` before every commit if you add new tools or local data.

## If you want stronger legal protection

- Register the game code and original artwork with the U.S. Copyright Office.
- Keep unreleased systems, notes, and business plans private if you want trade-secret protection.
- If the game name or logo will be public-facing, consider trademark registration.
